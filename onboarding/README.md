# Installation and first usage of treecript

This directory contains the files generated along the walk-through
shown at [Installing treecript (2025-11-05)](https://asciinema.org/a/754182)
(cast also [available here](installing_treecript.cast) to be viewed
locally using `asciinema play`), which downloads and runs
[download-and-test-linux-6.6.bash](../sample-work-to-measure/download-and-test-linux-6.6.bash).

* Folder [FIRST_MEASURE](FIRST_MEASURE) contains all the raw metrics
obtained from running the workload.

* Folder [FIRST_CHARTS](FIRST_CHARTS) contains all the generated basic charts
about all the processes tracked through the execution.

* Folder [AGG_CHARTS](AGG_CHARTS) contains all the generated aggregation charts
about the set of processes tracked through the execution.
